# Guia 1 Mi propio caso de negocio

## Datos del negocio

- Nombre del negocio; NOCTUA — Beyond Digital.
- Quien lo dirige; SANTIAGO ORELLANA RIVERA.
  -Tipo de negocio: Servicio freelance de diseño y desarrollo de páginas web.

## Situacion Actual

Actualmente no cuento con un portafolio web profesional que permita mostrar de manera organizada y detallada mis proyectos, servicios y trabajos realizados. Esto dificulta que los posibles clientes puedan conocer mi trabajo, observar la calidad y funcionalidad de mis páginas web y comunicarse conmigo de manera organizada.

## Problema

La falta de un sistema web profesional dificulta mostrar mis proyectos de manera completa y administrar la interacción con los posibles clientes. Los visitantes pueden conocer parcialmente mi trabajo, pero no cuentan con un espacio donde puedan acceder a información detallada de los proyectos, enviar mensajes, solicitar cotizaciones o agendar reuniones de manera organizada.
Además, no existe un sistema diferenciado que permita administrar los proyectos y clientes desde un área privada.

## Lo que necesita

Un sistema web profesional denominado NOCTUA — Beyond Digital, que funcione como portafolio de servicios freelance de diseño y desarrollo web.

El sistema deberá manejar tres niveles de acceso: visitante, cliente y administrador.

El visitante podrá explorar libremente la información pública del portafolio, proyectos, servicios y contenido de NOCTUA. Cuando quiera acceder a información detallada de un proyecto o utilizar funciones como enviar mensajes, solicitar cotizaciones o agendar reuniones, deberá registrarse como cliente.

El cliente registrado tendrá acceso a un área privada donde podrá consultar proyectos de manera detallada e ilimitada, visualizar sus propios proyectos, consultar sus estados y avances, enviar mensajes, solicitar cotizaciones, gestionar reuniones y administrar su información personal.

El administrador tendrá acceso completo al sistema, pudiendo gestionar proyectos, clientes, servicios, solicitudes, cotizaciones, citas, mensajes, usuarios y demás información del sistema.
